# Movie Project

A full-stack movie booking application with React frontend and FastAPI backend.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: SQLite/PostgreSQL (configured in database.py)

## Getting Started

### Backend
1. `cd backend`
2. `python -m venv venv`
3. Activate virtual environment
4. `pip install -r requirements.txt` (if available)
5. `uvicorn app.main:app --reload`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
